# RankStyleAI website

Sito statico ufficiale di RankStyleAI, pubblicato con Cloudflare Pages tramite
il repository GitHub `Mauriziopizzolante/rankstyleai-site`.

Contiene homepage, Privacy Policy, Termini di utilizzo e pagina Supporto in
italiano e inglese. Alla prima visita viene scelta la lingua del dispositivo:
italiano per impostazioni `it-*`, inglese per tutte le altre. Il selettore
IT/EN permette di modificare e salvare la scelta nel browser.

Tutti i collegamenti interni sono relativi.
